# Using dolly

dolly finds duplicated code in Swift: exact, near and structural clones, and with an embedding model, clones written in
different idioms.

- [Getting started](getting-started.md): install, run, where duplication lives, adopting it, accepting a finding.
- [Rules](rules.md): the four kinds of clone and how they are found.
- [Configuration](configuration.md): thresholds, severities, and a gating policy.
- [Using it in CI](integration.md): pull-request gates and code scanning.
- [Command line and reports](reports.md): options, the JSON report, stability.
- [Semantic clones](semantic.md): the experimental embedding pass (macOS).
