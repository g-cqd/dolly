## Configuration

- The shared `.swift-analyzers.json` (top-level shared keys, one section per tool) is read beside the tool's own file, found from a subdirectory too, nearest first (ADR-0021).
- A configuration with an unknown or repeated key now exits 78; before, it was ignored.
- `exclude` follows ADR-0008: a glob matched against the path relative to the configuration's directory.

## Cache

`--cache-path` names a root directory now (ADR-0011): facts sit in sharded files under `<root>/facts/<workspace>/`, keyed by file metadata then content, and memory-mapped. Payloads are protobuf. A tool keeps 512 MiB at most and evicts the least recently used workspaces first. A v1 cache file at the same path is replaced. The default root is `~/Library/Caches/<tool>` on macOS and `$XDG_CACHE_HOME/<tool>` (or `~/.cache/<tool>`) on Linux. On a CI runner, delete the old v1 cache files once; the tool would replace them anyway.
Extraction depends on no configuration, so changing rules or thresholds reuses every file; before, any configuration
change emptied the cache. On maintastic the cache went from 26 to 8 MB. Old `~/Library/Caches/dolly/<workspace>/facts.json`
files are no longer read and can be deleted.
